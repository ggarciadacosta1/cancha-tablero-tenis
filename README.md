# Cancha

Tablero de tenis táctil para tablet o celular. PWA sin backend, cuenta ni dependencias. Los partidos, fotos comprimidas e historial de tantos se guardan en el almacenamiento local del navegador.

## Iniciar

Serví esta carpeta mediante HTTP local (por ejemplo, con Python instalado: `python -m http.server 8000`) y abrí `http://localhost:8000` desde el mismo dispositivo.

**Tablet Android:** abrí [Cancha en GitHub Pages](https://ggarciadacosta1.github.io/cancha-tablero-tenis/) con Chrome y conexión, esperá la primera carga completa y abrí el menú ⋮ → **Instalar app** (o **Agregar a pantalla principal**). Abrila desde el icono y probá un partido corto. Después activá modo avión, cerrá y volvé a abrir la app para comprobar que la instalación concreta funciona sin conexión **antes del torneo**. Exportá un respaldo desde la tablet. El HTTP de la IP local de la PC sirve para probar la interfaz si ambos dispositivos están en la misma red, **pero no habilita la PWA offline en Chrome Android**. `file://` tampoco admite service workers. No se ha comprobado aún el funcionamiento en la tablet real.

## Reglas y uso

- Al crear un partido, podés agregar un **detalle opcional** (hasta 120 caracteres), por ejemplo «Copa Semis club A vs club B». Se guarda con el partido y aparece en **Partidos**, en el tablero y en **Estadísticas**, además de los resúmenes compartidos o descargados. Los partidos y respaldos anteriores, sin este campo, siguen funcionando.
- Singles o dobles; las fotos son opcionales: «Galería» abre el selector de imágenes y «Tomar foto» solicita la cámara trasera en navegadores compatibles (si no hay soporte, puede abrir el selector habitual). La app comprime la foto antes de guardarla. Se elige el primer sacador y, en dobles, el segundo del equipo rival: los compañeros sacan tercero y cuarto. **Después de iniciar el partido**, antes del primer tanto de cada set, «Orden de saque» permite elegir qué compañero saca primero en cada pareja; **después del primer game**, la otra pareja todavía puede cambiar su sacador antes del primer tanto de su propio game de servicio. El equipo que sirve primero sigue la alternancia reglamentaria. Una vez jugado el primer tanto del game de servicio de una pareja, su orden queda fijo hasta el siguiente set. El saque del tie-break se alterna 1–2–2–2 entre sacadores del orden vigente.
- Mejor de tres sets: los dos primeros se juegan a seis games, con diferencia de dos; en 6–6 se disputa un tie-break a 7 con diferencia de dos. Si cada equipo ganó un set, el tercero es un **match tie-break a 10**, con diferencia de dos. Si un equipo gana los dos primeros, el partido termina ahí. En cada game rige ventaja, no punto decisivo.
- «Cambiar lados» invierte la disposición visual, **no** los equipos ni el servicio. No se realizan cambios automáticos de lado. El tablero muestra los tantos totales ganados por cada equipo (no solo los puntos del game actual). Al cargar un tanto, el equipo ganador y el jugador responsable se eligen con botones de un toque y muestran la foto si existe; **a la izquierda están los golpes ganadores** y **a la derecha los errores y faltas en contra**. Una marca junto al nombre señala al sacador actual. El juez atribuye los golpes ganadores al jugador que los ejecutó; **doble falta siempre al sacador** y **error no forzado al jugador que lo cometió**, nunca al equipo beneficiado. El tanto ganado sí suma al total del equipo ganador. «Otro» registra tantos no comprendidos en las categorías indicadas.
- Al iniciar corre el cronómetro. «Pausar partido» lo detiene durante interrupciones (por ejemplo, lluvia) e impide anotar tantos; «Reanudar» continúa sin sumar el tiempo de pausa. «Terminar anticipadamente» está disponible en cualquier momento posterior al inicio: por **abandono** gana el rival del equipo seleccionado; por **otro motivo** se cierra sin ganador y se puede escribir una explicación. En ambos casos se conservan el marcador y los tantos acumulados, y el reloj se detiene sin completar los sets. Deshacer el último tanto de un partido terminado **por marcador** lo reabre y reanuda el reloj desde el momento del deshacer; un cierre anticipado no se reabre con deshacer. Las correcciones recalculan el marcador y rechazan tantos posteriores a un final por marcador.
- En **Estadísticas**, elegí «Todo el partido» o un set iniciado para filtrar los tantos ganados, categorías y atribuciones individuales de dobles. Se muestran el tiempo de juego total y el de cada set, incluido el set actual o inconcluso. Cada set se mide desde el inicio del partido (o el último tanto del set anterior) hasta su tanto decisivo; el set inconcluso se mide hasta el momento de la consulta o el cierre anticipado. Se excluyen las pausas, pero se incluyen los descansos entre sets mientras el reloj siga en marcha. Los partidos anotados antes de esta versión mantienen sus tantos y estadísticas, pero pueden mostrar «No disponible» para duraciones por set: antes no se guardaba el tiempo de juego en cada tanto y no se puede reconstruir el efecto de las pausas. El tiempo total sigue disponible.
- Descargá o compartí el resumen desde **Estadísticas**: las categorías reflejan el filtro seleccionado, y el texto siempre incluye el tiempo total y los tiempos por set. Si no existe la API de compartir, se abrirá el cliente de correo con el resumen. No se envía correo automáticamente.
- **Respaldo** descarga todos los partidos como JSON, incluidas las fotos; «Restaurar» importa ese archivo y reemplaza los partidos con el mismo identificador. Los datos no se sincronizan: limpiar almacenamiento del navegador, usar modo privado u otro dispositivo puede perderlos. Hacé respaldos periódicos, especialmente durante un torneo.
- Para borrar un partido, abrilo desde **Partidos** y usá **Eliminar partido**. Se solicita confirmación porque también se eliminan sus fotos, tantos y estadísticas locales; se puede borrar tanto un partido finalizado como uno en curso. Exportá un respaldo antes si querés conservarlo.

Sin login, servidor ni sincronización entre dispositivos. El modo sin conexión requiere una carga exitosa previa bajo HTTPS (o localhost) en cada dispositivo.
